HOW DRAYN WORKS
1. An agent requests intelligenceA structured job describes the task and required capability.
2. DRAYN selects an eligible providerRouting uses declared capabilities, not a hard-coded node choice.
3. The provider returns a resultThe result can include output, status and supporting evidence.
